# ۰۷ — ارائه‌دهنده هوش مصنوعی (مدل زبانی)

مدل زبانی **فقط** برای دو کار اختیاری استفاده می‌شود:
1. پیش‌نویس خلاصه پایان جلسه (`analysis-service/app/report.py`).
2. (نقشه راه) قضاوت کم‌اطمینان «تغییر موضوع در پاسخ» و بخش‌بندی موضوعی متن.

هیچ‌کدام از آشکارسازهای رفتاری به مدل زبانی وابسته نیستند؛ سامانه بدون هیچ مدل زبانی کاملاً کار می‌کند (`RAVAN_LLM_PROVIDER=none` → `NullProvider` با قالب قطعی).

## پیکربندی
```
RAVAN_LLM_PROVIDER=none | anthropic | openai
RAVAN_LLM_MODEL=<شناسه مدل انتخابی شما>
ANTHROPIC_API_KEY=… / OPENAI_API_KEY=…
```
شناسه مدل عمداً در کد ثابت نشده است؛ آن را از مستندات رسمی ارائه‌دهنده انتخاب کنید.

## نگهبان‌ها
- **پرامپت سیستم** (`llm.SYSTEM_PROMPT`): فقط توصیف؛ بدون تشخیص، اختلال، هیجان قطعی، فریب، لبخند واقعی/ساختگی، امتیاز خطر؛ همیشه نسبت به خط پایه خود فرد؛ زمینه‌های بی‌خطر اول؛ نقل قول عبارات ایمنی بدون تفسیر؛ پایان با «پیش‌نویس برای بازبینی درمانگر. ارزیابی بالینی نیست.»
- **ورودی**: فقط داده ساخت‌یافته و بی‌نام (زمان‌ها، مقادیر، زمینه‌ها) و گزیده‌های متنی که درمانگر خودش دارد.
- **خروجی** از `guard()` می‌گذرد: جملات با الگوهای ممنوع (انگلیسی و فارسی) حذف و در `guardrail_removed` ثبت می‌شوند.
- **جریان کاری**: وضعیت `draft_pending_clinician_review` → درمانگر هر مورد را تأیید/ویرایش/رد می‌کند → فقط متن درمانگر در `report_versions` نهایی می‌شود.

## اقامت داده
اگر ارسال داده جلسه (حتی بی‌نام) به سرویس ابری مجاز نیست، از `none` استفاده کنید یا یک ارائه‌دهنده محلی (مدل روی سرور خودتان با همان رابط `Provider.complete`) اضافه کنید.
